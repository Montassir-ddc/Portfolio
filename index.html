Veille Technologique

Thème : l'IA au service du développement logiciel

Pourquoi ce thème ?

Les outils d'IA générative transforment le travail du développeur : écriture du code, tests automatisés, revue de code, refactoring. En tant que futur développeur SLAM, je dois comprendre ces outils, savoir les utiliser et connaître leurs limites, notamment en matière de sécurité et de protection des données.

Ma méthode de veille

Je suis des flux RSS regroupés dans Feedly, des alertes Google sur des mots-clés (« agent IA code », « Copilot », « sécurité code IA ») et je consulte chaque semaine des blogs techniques. Je note ensuite chaque actualité importante dans le tableau ci-dessous avec mon analyse.

Ce que j'en retiens

  • Le métier évolue : le développeur écrit moins de code à la main et passe plus de temps à décrire le besoin, à guider les agents IA et à vérifier leur travail.
  • La sécurité reste une responsabilité humaine : un code qui fonctionne n'est pas forcément sûr. Les tests, la relecture et la connaissance des failles (comme l'injection SQL) restent indispensables.
  • Les données comptent : avant d'utiliser un outil d'IA, il faut vérifier ce qu'il fait du code de l'entreprise, en lien avec le RGPD et la confidentialité.
  • Pour moi : je dois bien maîtriser les bases (algorithmique, SQL, POO, tests) pour pouvoir juger et corriger ce que l'IA propose.
